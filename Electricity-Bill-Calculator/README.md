# Electricity Bill Calculator

A simple C program that calculates an electricity bill based on the number of units consumed.

## Features

- Calculates electricity charges using different unit slabs
- Applies a 5% tax to the bill
- Displays the final electricity bill
- Uses conditional statements for slab-based calculation

## Concepts Used

- Variables
- Data types
- Arithmetic operators
- `if-else`
- Type casting
- Input and output
- Conditional logic

## How to Run

Compile the program using GCC:

```bash
gcc electricity_bill.c -o electricity_bill
