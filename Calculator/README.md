# Calculator

A simple menu-driven calculator written in C.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Remainder
- Division-by-zero validation
- Menu-based operation selection

## Concepts Used

- Variables
- Data types
- Type casting
- `switch`
- `if-else`
- Logical operators
- Input validation

## How to Run

Compile the program using GCC:

```bash
gcc Calculator.c -o Calculator
